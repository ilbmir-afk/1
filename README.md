# ElectroPlan PWA v2.0

Веб-приложение для проектирования электрических систем.

## Возможности

### Загрузка плана помещения
- Поддержка изображений: PNG, JPG, SVG, PDF
- Drag-and-Drop для загрузки
- Настройка масштаба

### Библиотека оборудования
- 🔌 Розетки и выключатели
- 💡 Освещение
- 🔥 Бытовая техника
- ⚡ Щиты и панели
- 📦 Распределительные коробки (РК)

### Проектирование
- Drag-and-Drop размещение элементов
- Автоматическая прокладка кабелей
- Прокладка через распределительные коробки (если добавлены на план)
- Расчёт сечения кабеля по ПУЭ

### Расчёты
- Суммарная нагрузка
- Расчётный ток
- Проверка по нормам ПУЭ/ГОСТ

### Материалы и смета
- Автоматическая спецификация
- Расчёт стоимости
- Экспорт макета отчета

### PWA
- Установка на устройство
- Офлайн-режим
- Автосохранение

## Запуск

```bash
python -m http.server 8000
```

Откройте http://localhost:8000/electroplan-pwa/

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| V | Выделение |
| H | Перемещение |
| A | Автопрокладка кабелей |
| F5 | Расчёт нагрузок |
| Ctrl+S | Сохранить |
| Ctrl+Z | Отменить |
| Ctrl+Y | Повторить |
| Delete | Удалить |
| Escape | Сброс |
